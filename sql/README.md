# SQL Analysis

This folder contains the SQL queries used in the Logistics Operations & Fleet Performance Analytics project.

The queries were developed using MySQL Workbench to validate, explore, and analyse logistics and fleet performance data.

## Analysis Areas

* Load and trip performance
* Delivery timeliness and facility detention
* Revenue and revenue per mile
* Fuel expenditure and fuel efficiency
* Truck maintenance costs
* Fleet utilisation
* Data quality checks

**Database:** MySQL
**Tools:** MySQL Workbench and SQL
