# SQL Analysis

This folder contains the SQL queries used to validate, explore, and analyse the logistics datasets for the Logistics Operations & Fleet Performance Analytics project.

The analysis covers:

* Data quality and validation checks.
* Load and trip performance.
* Delivery timeliness and facility detention.
* Revenue and revenue per mile.
* Fuel expenditure and fuel efficiency.
* Truck maintenance costs.
* Fleet utilisation.

**Database:** MySQL
**Tools:** MySQL Workbench and SQL
