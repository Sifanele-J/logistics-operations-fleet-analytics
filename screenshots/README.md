# Dashboard Screenshots

This folder contains screenshots of the three Power BI dashboard pages developed for the Logistics Operations & Fleet Performance Analytics project.

* **Executive Overview:** Revenue, loads, mileage, delivery timeliness, and detention.
* **Service & Route Performance:** Route reliability, facility detention, and revenue efficiency.
* **Fleet & Driver Performance:** Fuel expenditure, truck maintenance costs, and fleet utilisation.

These visuals provide a quick overview of the analysis and its key performance indicators.
