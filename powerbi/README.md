# Power BI Dashboard

This folder contains the Power BI report developed for the Logistics Operations & Fleet Performance Analytics project.

The dashboard includes three pages:

1. **Executive Overview** — Key performance indicators, monthly revenue trends, booking types, and delivery timeliness.
2. **Service & Route Performance** — On-time delivery by route, average detention by facility, and revenue per mile by route.
3. **Fleet & Driver Performance** — Monthly fuel expenditure, maintenance costs by truck, and average fleet utilisation.

**Tools:** Power BI, DAX, Power Query, and MySQL.
